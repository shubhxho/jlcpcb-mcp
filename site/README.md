# jlcpcb-mcp site

Static single page (plain HTML/CSS, no build step) deployed to Vercel at https://jlcpcb-mcp.vercel.app.

- `index.html` – generated by `scripts/build_site.py` from `samples.json` (live tool outputs).
- `scripts/capture_samples.py` – re-captures `samples.json` by running the release binary against the live JLCPCB/LCSC endpoints.
- `jlcpcb-mcp-guide.pdf` – copied from `docs/` by `build_site.py` (gitignored; deployed alongside `index.html`).
- `preview.png` – headless-Chrome render of the production page.

Refresh: `cargo build --release && python3 site/scripts/capture_samples.py && python3 site/scripts/build_site.py`, then deploy `index.html` + `jlcpcb-mcp-guide.pdf`.
