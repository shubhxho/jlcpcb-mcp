JLCPCB & LCSC parts, live in your AI assistant

jlcpcb-mcp lets Claude, Cursor or any MCP client search JLCPCB's assembly catalog in real time: stock, price breaks, Basic / Preferred / Extended class, datasheets, cheaper alternatives and rough PCB estimates. No API key required.

Status

service_status

Uncached reachability and latency checks for the JLCPCB and LCSC endpoints, plus whether the optional official API is configured.

Arguments no arguments

{
  "version": "0.1.0",
  "jlcpcb_parts_api": {"detail": "reachable (live search probe)", "latency_ms": 345, "ok": true},
  "lcsc_api": {"detail": "reachable", "latency_ms": 145, "ok": true},
  "official_api_configured": false
}

Errors are tool results, not crashes

Bad input and missing parts come back as isError results with an actionable message (live outputs):

{
  "isError": true,
  "message": "part C999999999 was not found at JLCPCB or LCSC"
}
{
  "isError": true,
  "message": "invalid input: category \"mlcc\" is ambiguous (2 matches). Use one of: Multilayer Ceramic Capacitors MLCC - Leaded (in Capacitors); Multilayer Ceramic Capacitors MLCC - SMD/SMT (in Capacitors)"
}

Install

Requires a Rust toolchain (1.89+). Both commands put a jlcpcb-mcp binary in ~/.cargo/bin.

From GitHub once the repo is published

Available as soon as the repository is public at github.com/shubhxho/jlcpcb-mcp.

cargo install --git https://github.com/shubhxho/jlcpcb-mcp

From a local checkout

Works today from the source tree.

cd jlcpcb-mcp
cargo install --path .
jlcpcb-mcp --version   # jlcpcb-mcp 0.1.0

Optional: set JLCPCB_APP_ID, JLCPCB_API_KEY and JLCPCB_API_SECRET to also query JLCPCB's official Open API. JLCPCB_MCP_TIMEOUT_SECS (default 20) and JLCPCB_MCP_LOG (default warn) tune behaviour.

Data sources & limits

Nothing is bundled or scraped into a local database: each call goes to the live endpoints below.

EndpointUsed forAuth
jlcpcb.com … /selectSmtComponentList/v2Search, category tree, alternativesnone
jlcpcb.com … /getComponentDetailAssembly stock, price breaks, attributesnone
wmsc.lcsc.com/ftps/wm/product/detailLCSC retail stock and prices, datasheetnone
open.jlcpcb.com … /getComponentDetailByCodeOfficial API (optional)HMAC-SHA256

Limitations

  • The JLCPCB and LCSC web endpoints are undocumented and can change without notice.
  • estimate_pcb_quote is an approximate parametric model, not a JLCPCB quote. Always confirm at cart.jlcpcb.com/quote.
  • Alternatives are rule-based (category, package, key value); check ratings and tolerances in the datasheet before substituting.
  • Stock and prices are a snapshot at call time.
